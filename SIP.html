Innovation Clam

Another Way is a game concept that explores how people with different ways of processing information can experience the same environment differently. The game uses one maze but gives each character different ways of noticing and interpreting clues. The goal is to show that there can be more than one way to understand and solve the same problem.

Project Description

Another Way is a maze-based game featuring three characters who approach the same environment in different ways. The maze contains many branches but only a small number of paths lead to the correct solutions. The three characters include a character who notices counting and pattern based information, a deaf character who relies on visual information, and a regular/hearing character. The environment stays the same but the information each character is able to notice and use changes how the maze is solved.

Clues are designed to be subtle at first. A clue that may be easy to overlook when playing as one character can become more noticeable or meaningful when playing as another. This allows the same maze to provide a different experience each time it is played. The project focuses on different strengths and ways of processing information rather than treating accessibility differences as limitations. The goal is to create a mechanic that encourages players to look at the same environment from another perspective.
